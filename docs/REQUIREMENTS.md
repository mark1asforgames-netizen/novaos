# Aparatūros reikalavimai (planuojami, NEPATIKRINTI realioje aparatūroje)

Orientaciniai (Debian 13 + Plasma 6). Jokių NovaOS-specifinių matavimų dar nėra.

| | Minimumas | Rekomenduojama |
|---|---|---|
| Architektūra | x86-64 (64 bit) | x86-64 |
| Paleidimas | UEFI arba BIOS. **Secure Boot: nepatikrinta, išjunkite** | UEFI |
| CPU | 2 branduoliai | 4+ branduoliai |
| RAM | 4 GB | 8 GB+ |
| Diskas | 25 GB | 64 GB+ SSD |
| Grafika | OpenGL 2.0+ (Intel/AMD atviros tvarkyklės) | Intel/AMD iGPU ar dGPU |

Svarbu: NVIDIA, naujausi Wi-Fi lustai, kai kurie nešiojamų kompiuterių jutikliai ir pirštų atspaudų
skaitytuvai gali reikalauti papildomų tvarkyklių. **Nespėliojame**: suderinamumas bus nurodytas tik
po testų konkrečioje aparatūroje.

Windows .exe: ne native. Bus tik pasirenkamas Wine sluoksnis, be jokios 100 % suderinamumo garantijos.
